# UI component catalog

Cypress catalog attributes and style usage for the front application.

**Canonical extract (tags + styles):** [cy-tags-and-styles.md](./cy-tags-and-styles.md)

That file lists every `cy-section-name`, `cy-field-value`, `cy-field-label`, and `cy-name` in use, describes them, documents global styles under `src/styles/`, and lists component-scoped styles used outside the global sheets.

When a component is added or its tags / shared classes change, update `cy-tags-and-styles.md` in the same change.
